# 모험가 길드 — 반복 의뢰 · F~S 승급 · 뒷거래

## 현재 구현 완료 (2026-10-06)

길드는 루크레아의 반복 수입원이다. 핵심 루프는 **의뢰로 돈을 번다 → 하루 한도를 채운다 → 돈을 내고 더 일한다 → 승급비를 내고 시험 본다 → 더 높은 등급 의뢰를 받는다**이다.

### 1. 공식 등급
| 등급 | 대응 티어 | 보상 배율 |
|---|---:|---:|
| F | T1 | ×1.00 |
| E | T2 | ×1.10 |
| D | T3 | ×1.20 |
| C | T4 | ×1.30 |
| B | T5 | ×1.40 |
| A | T6 | ×1.50 |
| S | T7 | ×1.60 |

- 새 게임은 F급부터 시작.
- 예전 길드 저장에 등급 필드가 없으면 현재 플레이어 레벨 티어에 맞는 등급으로 1회 이관한다.
- 게시판 의뢰 티어는 **min(플레이어 레벨 티어, 길드 등급 티어)**.
- S급이 공식 최종 등급. SS급은 구현하지 않는다.

### 2. 반복 의뢰 게시판
- 큰 마을 길드 홀 앞 게시판 또는 길드장 하르트의 `의뢰 보기`.
- 게시판에는 항상 후보 6개를 유지한다.
- 후보 순환: 일반 처치 2 / 특정 몬스터 처치 2 / 던전층 도달 1 / 무역품 납품 1.
- 동시에 진행 가능한 반복 길드 의뢰 최대 5개.
- 수락한 자리는 즉시 새 후보로 보충된다.
- 본편·연쇄·서브 의뢰는 길드 일일 횟수와 진행 5개 한도에서 제외.

### 3. 하루 10건과 새벽 4시 초기화
- 반복 길드 의뢰는 실제 시간 기준 **하루 기본 10건 수락 가능**.
- 하루 경계는 자정이 아니라 **새벽 4시**.
- 04:00이 지나면 `todayAccepted=0`, `bribeCount=0`으로 초기화되고 게시판 후보도 새로 생성.
- 진행 중이던 의뢰는 날짜가 바뀌어도 유지.
- 등급이 높아져도 기본 10건은 늘지 않는다.

### 4. 뒷거래
기본 10건을 모두 수락한 뒤 추가 의뢰를 원하면 접수원이 장부의 '빈칸'을 제안한다.

| 횟수 | 추가 수락 | 비용 |
|---|---:|---:|
| 1회 | +3건 | 추가 3건 예상수익의 30% |
| 2회 | +3건 | 45% |
| 3회 | +3건 | 60% |

- 하루 최대 3회. 최종 한도는 **19건**.
- 비용은 현재 받을 수 있는 의뢰 티어·현재 레벨·현재 등급 보상 배율로 계산한 3건 예상 골드를 기준으로 한다.
- 선불이며 환불 없음.
- 19건 이후 접수원은 더 이상 받지 않는다.
- 대사는 시스템 설명이 아니라 장부 빈칸·잉크값 등 생활형 뒷거래 대사로 표현한다.

### 5. 승급 신청 조건
다음 등급으로 가려면 아래 조건을 모두 충족해야 한다.
1. 다음 티어 최소 레벨 도달: E Lv11 / D Lv21 / C Lv31 / B Lv41 / A Lv51 / S Lv61.
2. **현재 등급에서 반복 의뢰 20건 완료**.
3. 시험비를 낼 금화 보유.
4. 신청 후 지정 승급 보스 처치.

시험비는 **현재 등급 대표 하루수입 × 3.5일치**로 자동 계산한다.
대표 하루수입은 해당 등급 티어의 최고 레벨 기준 평균 의뢰 골드 × 10건 × 등급 배율이다. 모든 숫자는 `guild.js` 상수/함수에 모아 둔다.

### 6. F→S 승급시험
승급은 다음 티어의 보스를 미리 잡는 것이 아니라 **현재 등급의 최종 보스를 잡고 다음 등급으로 올라가는 구조**다.

| 승급 | 최소 Lv | 시험 목표 |
|---|---:|---|
| F → E | 11 | 지하 3층 킹슬라임 |
| E → D | 21 | 지하 6층 고목 정령 |
| D → C | 31 | 지하 9층 철퇴 오우거 무리장 |
| C → B | 41 | 지하 12층 설원 늑대 무리장 |
| B → A | 51 | 지하 15층 얼음 갑주 무리장 |
| A → S | 61 | 지하 18층 붉은 비늘 드래곤 |

- 새 몬스터를 만들지 않고 기존 층 우두머리를 사용한다.
- 시험 신청 순간 시험비가 빠진다.
- 시험비는 **성공·실패·포기 모두 환불하지 않는다**.
- 시험 보스를 잡아도 자동 승급하지 않고 큰 마을 길드로 돌아와 **하르트에게 합격 보고**해야 등급이 오른다.
- 승급하면 `rankDone`은 0으로 돌아가며 새 등급 의뢰 게시판이 즉시 생성된다.
- S급 달성 후 공식 승급 버튼은 종료 상태가 된다.

### 7. 시험 실패와 포기
- 승급시험 진행 중 실제로 쓰러져 마을로 귀환하면 시험 상태가 실패로 바뀐다.
- 부활 스킬로 즉시 살아난 경우는 실패로 처리하지 않는다.
- 실패 후 하르트에게 돌아오면 실패 대사가 나오며 시험비는 반환되지 않는다.
- 진행 중 시험을 포기할 때는 환불 없음 경고 후 한 번 더 눌러 확정.
- 다시 응시하려면 조건을 갖춘 상태에서 시험비를 다시 낸다.

### 8. 하르트와 대사
- 하르트 대화창에는 `의뢰 보기`와 별도로 **승급 시험** 버튼이 있다.
- F→S 여섯 승급 장면은 각각 다른 하르트 대사를 사용한다.
- 대사는 `docs/dialogue_rules.md` 기준: 보스/비용을 메뉴얼처럼 읽지 않고, 과거 응시자·장비·술·길드 일상 이야기 속에서 자연스럽게 시험 이야기가 나온다.
- 합격·실패도 자동 감사문이나 시스템 문구 대신 하르트와 루크레아 관계가 보이는 장면으로 처리한다.

### 9. 저장
`guildState` 저장 필드:
- `rank` 0~6
- `rankDone` 현재 등급 완료 횟수
- `dayKey` 새벽4시 기준 날짜
- `todayAccepted`
- `bribeCount`
- `exam` 승급시험 상태/목표/시험비
- 기존 `seq / board / active / completed`

재시작해도 오늘 받은 횟수·뒷거래 횟수·시험 상태가 유지된다.

### 10. 자동검사
- 기존 `check_guild.py`: 게시판/5개 진행/HUD/처치/던전/납품/저장/포탈.
- `check_guild_rank.py`: 04시 초기화, 일일10건, 뒷거래 30/45/60, 최대19건, F→S 6단계, 시험비, 지정 보스, 패배 실패, 저장/옛 저장 이관.
- 전용 빠른 검사 `guild-rank-smoke`로 승급 시스템만 별도 검증 가능.
