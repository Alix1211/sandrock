# 능력치·스킬·숙련·생활성장 (2026-10-03 장기 성장판)

## 기본 성장
- 레벨 상한: **70**.
- 레벨업마다 능력치 포인트 +5. 10의 배수 레벨은 +10.
- 레벨업마다 전투 스킬 포인트 +1.
- 5레벨마다 생활 포인트 +1.
- 운은 직접 투자하지 않고 5레벨마다 자동 +1. 장비 옵션으로도 추가 가능.
- 전투 스킬 포인트는 액티브와 패시브가 공유하며 아껴 둘 수 있다.
- 생활 포인트는 전투 포인트와 완전히 분리.

## 직접 투자 능력치
- 힘 STR: 물리 기본공격·물리 스킬 피해 기반.
- 체력 VIT: 최대 HP.
- 지능 INT: 마법 기본공격·마법 스킬 피해 기반.
- 마력 MAG: 최대 MP.
- 민첩 DEX: 공격속도, 약간의 이동속도, 소량의 치명타.
- 운 LUCK: 자동성장 + 장비. 골드/파밍 계열에 영향.

현재 실제 계산의 핵심:
- 최대 HP = 20 + VIT*5 + 장비 HP.
- 최대 MP = 10 + MAG*4 + 장비 MP.
- 공격속도 = DEX*0.45 + 장비 공격속도 + 무기숙련 + 연속동작 패시브.
- 치명타 기본 5% + DEX 소량 + 장비 + 정밀타격 패시브, 현재 상한 65%.
- 기본 치명타 피해 150% + 장비 옵션.
- 방어력과 생존본능 패시브가 실제 받는 피해를 줄이며 현재 상한 65%.

## 무기 숙련
검·창·건틀릿·활·지팡이 각각 별도이며 **Lv0~50**.
- 실제 기본공격이 적에게 적중할 때 숙련 경험치 +1.
- 스킬 공격만 난사해서 숙련을 올릴 수는 없다.
- 필요 숙련 EXP: 25 + 12*현재숙련Lv + 1.2*현재숙련Lv^2 반올림.
- 한 무기 숙련 50까지 계산상 약 64,000회 기본공격 적중이 필요.
- 숙련 Lv1당 해당 무기 피해 +0.5%, 공격속도 +0.15%.
- 초반 숙련은 비교적 빨리 오르고 고숙련은 장기 목표.

## 현재 실제 구현된 액티브 스킬
현재 효과까지 구현된 스킬은 5개이며 각각 Lv0~5 투자식이다.
- 불덩이 fire1 — 시작 Lv1. 랭크당 피해 증가. 화염/스킬피해 장비 옵션 적용.
- 빙결 보호막 ice1(구 얼음 화살/알갱이) — Lv0부터 투자. 랭크당 흡수량·지속·빙결 시간 증가. 스킬피해 옵션이 흡수량에 적용.
- 치유 holy1_heal — 랭크가 높을수록 회복 비율 증가.
- 강하게 베기 sword1 — 물리/스킬 피해와 랭크 적용.
- 회전 베기 sword2 — 물리/스킬 피해와 랭크 적용.

나머지 계획된 마법/무기 스킬 아이콘과 자리는 유지하지만 아직 실제 효과 미구현. 미구현 스킬은 투자 불가.

## 패시브 스킬
액티브와 **같은 전투 스킬 포인트**를 쓴다.

| 패시브 | 최대 | 현재 효과 |
|---|---:|---|
| 마력 유도 | 3 | 마법/지팡이 투사체 유도 거리·추적력 증가. 시작 0 |
| 정밀 타격 | 5 | 치명타 확률 +2%/Lv |
| 연속 동작 | 5 | 공격속도 +3%/Lv |
| 마력 순환 | 5 | 스킬 마나 소모 -4%/Lv |
| 생존 본능 | 5 | 받는 피해 감소 +3%/Lv |
| 탐욕의 눈 | 5 | 아이템 발견 +5%, 골드 획득 +3%/Lv |

마력 유도는 더 이상 기본 활성화가 아니다. 투자하지 않으면 투사체는 바라보는 방향으로 직선 발사하며 벽에 막힌다.

## 생활스킬
생활스킬은 정해진 레벨에 Lv1 자동 해금되고, 이후 5레벨마다 받는 생활 포인트로 강화한다.

| 생활스킬 | 해금 | 최대 | 성장 효과 |
|---|---:|---:|---|
| 타운 포탈 | Lv3 | 3 | 재사용 15분 → 8분 → 3분 |
| 감정 | Lv7 | 3 | 마법 → 희귀 → 전설 장비 자가 감정 방향 |
| 디스카운트 | Lv12 | 5 | 구매가 -2%/Lv, 최대 -10% |
| 오버카운트 | Lv18 | 5 | 판매가 +2%/Lv, 최대 +10% |
| 마법부여 | Lv25 | 5 | 부여 기능/비용 효율 향상 방향 |
| 돈 냄새 | Lv35 | 5 | 아이템 발견 및 희귀도 쪽 보너스 증가 |

현재 실제 연결 상태:
- 타운 포탈: 사용 버튼과 재사용시간 적용 완료.
- 디스카운트: 일반 상점과 무역 매입가에 실제 적용.
- 오버카운트: 일반 상점과 무역 매각가에 실제 적용.
- 돈 냄새: 아이템 발견과 희귀도 롤에 실제 적용.
- 감정·마법부여: 랭크/투자 구조는 구현됐으나 실제 감정/마법부여 시설·UI는 아직 다음 작업.

## 장비 옵션과 성장의 관계
- 접두/접미는 무기 직업별로 과하게 제한하지 않는다.
- 물리공격%, 마법공격%, 공격속도, 치명타, 치명타피해, 화염/냉기, 스킬피해, 방어, HP/MP, 이동속도, 골드, 아이템발견, 운 등이 실제 계산에 연결.
- 따라서 같은 단계 장비라도 빌드와 옵션 조합에 따라 가치가 크게 달라져야 한다.
