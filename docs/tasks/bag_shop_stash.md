## 2. 가방 드래그앤드롭 + 자동 정리
- 칸끼리 **끌어다 놓으면 자리 바꿈**(빈 칸이면 이동). 터치와 마우스 모두 Pointer Events로.
- **탭(짧게 누름)은 지금처럼** 선택·비교 카드. 8px 이상 움직이거나 0.2초 이상 누른 뒤 움직이면 드래그. 끄는 동안은 그림이 손가락을 따라가고(고스트), 원래 칸은 흐리게.
- 장비 칸(왼쪽)에 놓으면 **착용**, 가방으로 끌면 **해제**(지금의 착용/해제 규칙·레벨 제한을 그대로 사용, 못 입으면 원위치).
- **자동 정리 버튼**(가방 틀 위쪽이나 아래쪽, 기존 버튼 모양): `티어` `가격` `종류` 세 개. 누를 때마다 같은 기준 내림차순, 빈 칸은 뒤로.
  - 티어순: 티어 높은 것 → 등급(일반<마법<희귀<전설) 높은 것 → 종류
  - 가격순: 판매 기준값(`baseSellValue`) 높은 것 → 낮은 것
  - 종류순: 무기(검·창·건틀릿·활·지팡이) → 방어구(머리·몸·손·발) → 장신구 → 소모품·기타. 같은 종류 안에서는 티어·등급 순
  - 입고 있는 장비는 건드리지 않는다. 정렬은 안정 정렬. 정렬 후 즉시 저장.
- 무역품(화물칸) 탭은 이번 범위가 아니다.

## 3. 상점을 디아블로식으로
- 상점을 열면 **왼쪽 상인 창 + 오른쪽 내 가방(위 2번과 같은 격자)**이 함께 열린다. 상인 창은 지금 `#shop`의 `GOODS` 목록·초상화·말풍선을 유지.
- **팔기**: ① 가방 물건을 끌어 상인 창에 놓는다, 또는 ② 가방 물건을 선택 → 설명 카드에 받는 값 → `팔기` 버튼. 희귀 이상(등급 2↑)은 확인 한 번. 팔 때의 값·매각 압력·가게별 시세(`sellPrice`, `sellRate`, `sellPressure`, economy.md)는 **그대로**.
- **사기**: 상인 물건을 가방 칸으로 끌어놓거나, 선택 → `사기`. 가방이 가득 차면 거절 문구.
- 값 표시: 칸 오른쪽 아래 숫자(받는 값/사는 값), 평소보다 높으면 ▲, 낮으면 ▼(지금 규칙).
- 입고 있는 장비는 팔기 목록에서 제외(실수 방지, 지금처럼).
- 기존 탭(사기·팔기)은 없애도 된다. 대신 같은 화면에서 둘 다 된다.
- 무역소(`TRADE`, 교역) 창은 이번 범위가 아니다.

## 4. 개인 창고
- **위치**: 마을 상점 옆. `src/town/build.py`의 소품 목록(`P`)에 **창고 상자**를 놓고, 가까이 가서 누르면(또는 대화 버튼) 창고 창이 열린다. 상점과 겹치지 않게 칸 좌표를 확인(`overlap.py`).
- **그림**: 케인이 첨부하는 창고 상자 그림을 `assets/town_props/`에 규칙대로 넣어 쓴다. 없으면 3번째 줄 규칙대로 멈추고 요청.
- **창**: 왼쪽 창고 격자 + 오른쪽 내 가방이 함께 열린다. 칸끼리 끌어 옮기고(가방↔창고), 창고에도 같은 자동 정리 버튼이 있다.
- **칸 수 기본안**: 7열 × 8행 = 56칸(케인이 테스트하고 조정). 상수 하나로 둔다.
- **들어가는 것**: 장비·재료·소모품. 무역품(화물)은 이번에는 제외(경제 균형 때문에 케인과 따로 정한다).
- **이용료 없음**, 마을 어디서든 같은 창고 하나. 필드·던전에서는 열 수 없다.
- **저장**: 창고 내용을 저장에 포함(옛 저장은 빈 창고). `초기화` 버튼을 누르면 같이 지워진다.
