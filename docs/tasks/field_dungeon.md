## 0. 지금 있는 것 (건드리기 전에 이해할 것)
- 게임은 HTML 한 파일: `game/town.html` ← `python3 src/town/build.py`로 만든다(첫 빌드 3분, 이후 캐시로 수 초).
- 코드: `src/town/town.js`(세계·이동·전투 모션·날씨·맵 전환), `src/town/ui.js`(HUD·가방·장비·스킬 탭·퀵슬롯·물약), `src/town/shell.html`(화면 틀·CSS), `src/town/build.py`(그림을 base64로 넣어 한 파일로), `src/town/outmap.py`(성 밖 갈림길 맵 = 작은 고정 맵의 본보기).
- 맵 전환 구조: town.js의 `MAPS`(마을 `town`, 성 밖 `out`)와 `buildWorld(id)`, `travel(id, 위치, 방향)`, 걸어 들어가면 이동하는 `exits`.
- 성 밖 갈림길: 왼쪽 냄비 투구 경비병(`go: 'field'`) → 지금은 "지역 선택은 다음 단계" 안내만. 오른쪽 동굴 입구·방패 경비병(`go: 'dungeon'`) → 안내만. **여기에 연결하는 것이 이번 일.**
- 전투 쪽 이미 있는 것: 무기 5종 기준값 `WB`(docs/weapons.md), 근접 판정·화살·구슬·폭발, 허수아비 타격(`dummies`, `hitDummy`), 피해 숫자, 시험용 스킬 5개(`cast`), 물약(`drink`).

## 1. 지역 선택창 (필드 길 경비병)
- 경비병 대화의 "지역 고르기" → 지역 목록 창(키트 `kit_c_04` 틀, 다른 창들과 같은 그림체).
- 지역 7개 = 바닥 타일 7테마: 봄 초원(spring) · 여름 숲(summer) · 가을 들판(autumn) · 겨울 설원(winter) · 얼음 지대(ice) · 화산 지대(volcano) · 늪지대(swamp).
- 진행도 5티어와 묶는다(docs/progression.md, docs/guild_system.md): 처음엔 봄 초원만 열림, 나머지는 잠김 표시(길드 등급으로 열림 — 시험판에서는 모두 열어도 됨).

## 2. 필드 (지역마다, 들어갈 때마다 생성)
- 케인 확정 구조: **뼈대는 고정**(입구, 동굴(던전) 입구, 특별한 자리: 야영지·폐허·제단 등) + **지형·소품·몬스터는 들어갈 때마다 랜덤**.
- 크기 가안: 60×40칸(칸=48). 입구(마을 쪽)에서 동굴 입구까지 길이 이어지게(흙길).
- 바닥: `assets/tiles/<테마>/`(grass, grass_flower, dirt, path, sand, water) + `assets/edges/`. 마을처럼 경계가 부드럽게 섞여야 한다(src/town/outmap.py `gen_ground` 참고). **게임 안에서 생성**해야 하므로 브라우저에서 캔버스로 합치는 방식이 필요(들어갈 때 한 번, 태블릿에서 0.5초 안).
- 소품: `assets/field_props/<테마>/NN_이름.png` 16종씩(나무·덤불·바위·통나무·풀·특수 소품·16번 동굴 입구). 나무는 우듬지 흔들림, 그림자(마을은 빌드 때 구웠지만 필드는 런타임에 간단한 타원/투영 그림자).
- 작은 마을(지역마다 상점 1~2·여관): 이번 일 범위 밖. 자리만 비워 둘 것. 경비병 그림 `assets/npc_guard/guard_sleepy.png`, `guard_mustache.png`는 작은 마을용.
- 미니맵·날씨·하루 주기는 마을 것을 그대로 쓴다.

## 3. 몬스터와 전투
- 그림: `assets/monsters_3dir/<이름>_{left,front,right}.png`(오크·하피·서큐버스·악마·토끼·드래곤·늑대·곰·도적·어둠 마법사·리치), `assets/monsters/`(단방향 75장: 고블린·오크·슬라임·가고일·미믹·해골·버섯·벌레·거미·정령). **`assets/monsters_v1/`(예전 시험장용)은 쓰지 말 것.**
- 필요한 것: 배회 → 발견하면 쫓기 → 공격(근접/원거리) → 피격(움찔·넉백·피해 숫자) → 죽음(사라짐·금화/아이템 떨어뜨림). 엘프도 맞으면 체력이 줄고, 0이 되면 쓰러져 마을로(들고 있던 금화 일부 잃음 — docs/economy.md 2번, 케인 확인 대기 중이니 일단 넣고 기록).
- 자동 조준: 공격 버튼을 누르면 가까운 적 쪽으로 몸을 돌린다. 적이 비스듬히 아래에 있으면 정면 대신 옆모습 공격(케인 합의).
- 기존 허수아비 판정(`hitDummy`)을 몬스터 공통 판정으로 일반화할 것.
- 드랍: 일단 금화와 장비(지금 ui.js `make` 수준). 접두·접미 옵션 파밍은 `src/farm.js`(예전 파밍 시험판)에 체계가 있으니 옮겨 오는 것은 다음 단계.

## 4. 던전 (동굴 입구에서) — ✅ Claude가 만듦(2026-10-03, src/town/dungeon.js). GPT는 이 부분 손대지 말고, 고칠 일이 있으면 dungeon.js만 고칠 것
- 층마다 랜덤 생성(방 + 복도), 아래층 계단. 타일 `assets/dungeon/tiles/`, 소품 `assets/dungeon/props/`(횃불·기둥·상자·통·항아리·해골·거미줄·가시함정·스위치·철창).
- 어둠 + 횃불·엘프 주변 빛(마을 밤 조명 방식 참고).
- 예전 테스트판(`src/game.js`)에 던전 생성 코드가 있지만 **옛 그림이 섞인 판이라 그대로 붙이지 말 것**(케인 원칙: 덧대어 키우지 말 것). 로직만 참고.

## 5. 꼭 지킬 것
- 한 화면이라도 최종 품질. 옛 그림과 새 그림을 섞지 않는다(docs/asset_rules.md).
- 무기 모션 확정 사항을 깨지 말 것: 걷기 땐 무기 숨김, 공격 시 무기는 몸 뒤, 아래 공격은 이펙트만, 무빙 어택(70%, 활 100%).
- 시나리오 봉인 파일(src/story*)은 케인에게 보여 주지 말 것.
- 검사는 화면 캡처 대신 오류·동작·숫자로(src/town/check_*.py 참고, playwright). 실제로 걸어서 이동하는 검사를 꼭 넣을 것(순간이동 검사로 성문 버그를 놓친 적 있음).
- 매 작업 후 `python3 src/town/build.py`로 game/town.html을 다시 만들고 커밋·푸시.
