# 설정 장부 (봉인본)

## 사용법
사슬을 쓸 때는 이 장부의 이름, 직업, 말투, 관계만 쓴다. 새 인물이 필요하면 먼저 여기에 추가한다. 엘프 주인공의 이름은 아직 정하지 않았으니 '엘프'로만 부른다.

## 마을 규칙
- 통화는 골드 하나. 은행은 없고 전당포와 마을 금고(관리인 페닉스)가 있다.
- 마법은 존재하지만 대부분 생활 수준(점치기, 약 제조, 불 피우기). 큰 마법은 드물고 값이 비싸다.
- 마을 출구는 성문 하나. 성 밖 갈림길에서 왼쪽은 필드(지역별로 작은 마을이 있음), 오른쪽은 동굴(던전 입구)이다. 던전은 층마다 테마가 다르다.
- 마을 사람은 엘프를 '돈 밝히는 모험가'로 안다. 세상을 구할 인물로는 아무도 생각하지 않는다.
- 엘프의 말투: 계산적이고 짧다. 감정이 올라오면 숫자로 말한다. 존댓말과 반말을 섞지 않고 대체로 공손한 장사꾼 말투.

## 주요 장소 (건물 이미지 매칭)
- 여관: 파란 지붕 민가. 주인 토비. 엘프의 방이 여기.
- 잡화점: 파란 지붕 상점. 주인 마르코.
- 도구점: 초록 차양 상점. 대장간과 이웃.
- 무기·방어구점: 붉은 지붕 상점. 주인 루나.
- 대장간: 회색 지붕, 화덕. 주인 그레타.
- 술집: 붉은 지붕 맥주잔 간판. 주인 브란.
- 길드 홀: 파란 기둥 건물. 길드장 하르트.
- 학자의 집: 돔 건물. 학자 에드먼.
- 마을 금고: 큰 석조 건물(저택형). 관리인 페닉스.
- 전당포: 3층 상가. 주인 고르던.
- 성문: 마을의 유일한 출구. 안쪽은 라이너·에다가 지키고, 성 밖 갈림길에는 투구 쓴 경비병들이 있다.
- 촌장 집: 초가집. 촌장 오토.

## 인물 48명 (초상화 시트 n2~n5 기준)
형식: 이름 — 직업 / 성격·말투 / 비밀 또는 고리

### 시트 1 (n2)
1. 라이너 — 성문 경비병(창) / 성실, 딱딱한 말투 / 월급이 밀린 상태
2. 에다 — 성문 경비병(창, 여) / 쾌활한 직언 / 라이너와 근무 짝, 월급 문제를 대신 따짐
3. 카이 — 개과천선한 전직 도둑 / 능글맞음 / 가게를 열 자금을 모으는 중
4. 로사 — 카이와 같은 전직 도둑(여) / 현실적 / 카이의 동업자
5. 토비 — 여관 주인 / 푸근, 말끝이 길다 / 손님에게 외상을 잘 줌
6. 미나 — 꽃장수 소녀 / 수줍음 / 꽃 축제의 주최를 꿈꿈
7. 팀 — 모험가 지망생 소년 / 의욕 과다 / 엘프를 우상으로 오해
8. 보니 — 토끼 인형을 안은 소녀 / 천진 / 고르던의 딸
9. 올로 — 짐 나르는 행상 청년 / 눈치 빠름 / 소문을 많이 안다
10. 카르멘 — 점쟁이 / 허세, 과장된 말투 / 예언이 자주 빗나감
11. 하크 — 매를 기르는 사냥꾼 / 과묵 / 매 이름은 '금화'
12. 핀 — 견습 대장장이 / 열정적 / 그레타의 제자

### 시트 2 (n3)
13. 닉 — 심부름 소년 / 빠른 말투 / 돈 되는 심부름만 함
14. 리라 — 꽃집 딸 / 다정 / 미나의 경쟁자 겸 친구
15. 오토 — 촌장(노인) / 느긋, 옛말 섞음 / 마을 기금 장부를 직접 관리
16. 마르타 — 약초 할머니 / 잔소리 / 약초 가격을 평생 안 올림
17. 피트 — 개구쟁이 소년 / 장난 / 던전 입구 근처를 몰래 드나듦
18. 보라 — 트윈테일 소녀 / 새침 / 보니와 닮았지만 남남
19. 야닉 — 배달부 청년 / 바쁨 / 배달 중 눈에 띄는 걸 다 기억함
20. 세라 — 파란 앞치마 식당 점원 / 야무짐 / 숫자에 밝음
21. 마르코 — 잡화점 주인 / 소심한 장사꾼 / 저울을 아낌
22. 아넬 — 과일 장수 소녀 / 명랑 / 과일 값을 깎아 주다 적자
23. 루나 — 무기·방어구점 주인(대장장이 소녀) / 직설 / 대장간 그레타와 앙숙
24. 바우 — 짐꾼 청년 / 힘세지만 순함 / 짐 무게로 사람을 판단

### 시트 3 (n4)
25. 레온 — 귀족 청년 / 허세 / 집안 돈으로 모험가 놀이
26. 이사벨 — 귀족 아가씨 / 우아, 은근한 독설 / 부채로 감정을 가림
27. 클라라 — 귀족 소녀 / 순진 / 고양이를 키움
28. 고르던 — 전당포 주인(노인) / 인색, 계산적 / 엘프와 말이 잘 통하는 상대
29. 에드먼 — 학자 / 말이 길다 / 감정(鑑定) 담당
30. 루트 — 음유시인 / 즉흥적 / 마을 소문을 노래로 퍼뜨림
31. 아르노 — 신참 기사 소년 / 긴장 / 하르트 길드장의 제자
32. 제니 — 견습 여 모험가 / 승부욕 / 엘프를 라이벌로 봄
33. 시안 — 숲 궁수 / 냉정 / 보수 없는 의뢰는 안 받음
34. 아리아 — 마법사 소녀 / 소심 / 마법을 쓸 때 손이 떨림
35. 그림자 — 후드 쓴 정체불명 / 말수 적음 / 의뢰 중개인이라 자칭
36. 페리 — 약초꾼 소녀 / 순박 / 던전 앞 풀밭에 약초를 키움

### 시트 4 (n5)
37. 도윈 — 젊은 기사(창) / 정의감 / 월급은 하르트가 지급
38. 세실 — 여 기사 / 냉철 / 도윈의 선배
39. 하르트 — 길드장(노기사) / 호탕 / 길드 회계를 안 봄
40. 브란 — 술집 주인 / 호탕, 너스레 / 외상 장부를 쓴다
41. 미라 — 술집 여급 / 싹싹 / 장부를 읽을 줄 앎
42. 그레타 — 대장간 주인(고글, 큰 망치) / 거침 / 재굴림 담당
43. 페닉스 — 마을 금고 관리인(서기, 안경) / 꼼꼼, 의심 많음 / 열쇠 꾸러미를 차고 다님
44. 이브 — 연금술사 소녀 / 호기심 / 시약 실험에 엘프를 끌어들임
45. 빈센트 — 제빵사 / 낙천 / 빵 값을 안 올리는 원칙
46. 로즈 — 재단사 / 사교적 / 고르던의 재혼한 아내, 보니의 새엄마
47. 조 — 마부(말과 동행) / 투덜 / 말 이름은 '당근'
48. 하이디 — 방랑 상인 / 말솜씨 최고 / 마을에 가끔 들름

## 대형 사슬 등장인물 고정
- 사슬 B: 상점 주인 마르코, 학자 에드먼, 길드장 하르트
- 사슬 E: 전당포 주인 고르던(의뢰인), 아내 로즈, 딸 보니, 금고 관리인 페닉스(배후)
- 사슬 F: 술집 여급 미라(지하 장부 인물), 술집 주인 브란(모름)
- 사슬 G: 술집 주인 브란(국자 알아봄), 방랑 상인 하이디(국자를 노림)
- 사슬 C: 여관 주인 토비
- 사슬 I: 도윈·세실 대신 은빛 기사(걷기 시트 캐릭터), 영웅 검사, 용족 소녀 사용
