# 중형·소형 사슬 (봉인본)

대형 사슬 A~J는 src/story.md에 있다. 인물은 bible.md의 이름만 쓴다.
태그: [코미디] [미스터리] [훈훈] [경제] [괴담] [모험]. 같은 태그가 3개 이상 연속하지 않게 배치.
각 사슬: 시작 인물 / 단계 / 단서 잡템 / 대형 사슬 연결 / 흥정 지점.

## 연결 지도 (대형 사슬 ↔ 중형·소형)
- A 도망간 채무자들 ← M14(카이·로사의 채무), M06(월급 지연의 채권), S12(외상 장부)
- B 속이 빈 저울추 ← M08(마차 바퀴), S03(열쇠), S04(학자 안경천)
- C 깨지 않는 손님들 ← M09(약초 값), S09(소음 민원), M15(꽃 변이)
- D 유령 세입자 ← M10(촌장 장부), S20(허수아비)
- E 집 나간 가족 ← M02(인형 편지), M04(음유시인 노래), M06(월급 지연)
- F 현상금 명단 ← S08(잔돈 사건), S12(외상 장부), M07(레온의 빚)
- G 녹슨 국자 ← M11(가짜 보물 지도), M13(매가 물어 온 조각), S19(모자)
- H 압류된 구역 ← M13, M08, M10, S06
- I 일당 동료들 ← M05(대장간 라이벌), M14
- J 석화된 집주인 ← S16(이브 시약), M09, M12

## 중형 사슬 15개 (각 4단계)

### M01 [코미디] 빵 도둑 — 빈센트
1. 빵이 아침마다 한 덩이씩 사라진다고 의뢰. 단서 잡템: 말 털 몇 가닥.
2. 범인은 마부 조의 말 '당근'. 조가 사료값을 아끼려 말을 빵집 앞에 세워 둠.
3. 조는 인정하지 않고, 빈센트는 빵을 한 번도 판 적 없다고 주장하며 값을 흥정.
4. 엘프의 결론: 말이 먹은 빵값을 조가 내고, 대신 말이 빵집 문지기가 되어 손님이 늘어남. 사료비 절약 아이디어를 엘프도 몰래 배워 감.

### M02 [미스터리] 사라진 토끼 인형 — 보니
1. 인형이 던전 입구 쪽으로 굴러갔다는 의뢰. 단서 잡템: 인형 속에 꿰맨 작은 편지.
2. 던전 1층에서 인형을 찾음. 편지는 고르던의 필체로 쓰인 '아내와 딸에게'.
3. 편지의 내용은 평생 모은 재산을 숨긴 장소의 암호.
4. 보니에게 인형만 돌려주고 편지는 고르던과 거래할지 엘프가 고민. 사슬 E에서 다시 쓰임.

### M03 [코미디] 빗나가는 예언 — 카르멘
1. 의뢰: 자기 예언이 계속 틀리니 원인을 찾아 달라.
2. 단서 잡템: 금이 간 수정구 조각.
3. 알고 보니 수정구가 엘프의 통장 잔고를 먼저 읽어서 모든 예언이 "큰돈이 들어온다"로 변함.
4. 엘프는 수정구 속 숫자가 사실이면 좋겠다고 생각. 카르멘이 예언료를 깎아 주는 대신 앞으로 엘프의 운을 점쳐 줌.

### M04 [미스터리] 노래에 숨은 소문 — 루트
1. 루트의 신곡 가사에 마을 사람만 아는 사실이 섞여 의뢰인이 항의.
2. 단서 잡템: 찢긴 일기장 한 장.
3. 일기의 주인은 금고 관리인 페닉스. 루트가 우연히 주워 가사로 씀.
4. 페닉스의 일기에 금고 열쇠가 하나 더 있다는 내용. 사슬 E의 배후로 이어짐.

### M05 [코미디] 두 대장간 — 그레타, 루나, 핀
1. 두 대장간이 명장 대회에서 대결. 재료값 담합 의혹.
2. 단서 잡템: 속이 비어 있는 망치 자루.
3. 담합이 아니라 같은 도매상이 두 곳에 같은 품질의 철을 몰래 섞어 팔고 있었음.
4. 엘프가 도매상을 압박해 그레타·루나 양쪽에 수수료를 받고 연결해 줌. 사슬 I의 동료 장비 단서.

### M06 [경제] 밀린 월급 — 라이너, 에다
1. 성문 경비병 월급이 두 달째 밀림. 의뢰: 금고에서 받아 와 달라.
2. 단서 잡템: 서명이 빈 지급 전표.
3. 금고 관리인 페닉스가 전표 서명을 일부러 안 한 이유는 지급할 돈이 부족해서.
4. 금고 돈이 어디로 샜는지 추적. 사슬 E, A로 이어지는 갈래.

### M07 [코미디] 도련님 모험가 놀이 — 레온
1. 귀족 레온이 모험가로 위장해 던전 1층에 들어갔다는 의뢰.
2. 단서 잡템: 비단 장갑 한 짝.
3. 레온은 수업료를 아끼려고 도망쳤고 빚도 졌음.
4. 엘프가 빚 일부를 대신 갚고 수수료를 챙김. 사슬 F의 명단에 레온의 이름이 올라 있음.

### M08 [모험] 사라진 바퀴 — 조
1. 마차 바퀴가 하나씩 사라짐.
2. 단서 잡템: 바퀴 축에 새겨진 문장.
3. 던전 입구 문의 장식 부품이 마차 바퀴를 본떠 만든 것이라 문이 바퀴를 끌어당김.
4. 문 쪽을 고쳐 바퀴를 되찾고, 문 수리비를 마을에 청구. 사슬 B, H와 연결.

### M09 [경제] 약초 값 담합 — 마르타, 이브
1. 약초 값이 두 배로 오르자 항의가 쏟아짐.
2. 단서 잡템: 말라 버린 풀 뿌리.
3. 담합이 아니라 던전 안 약초 서식지가 바뀌어 공급이 줄어든 것.
4. 엘프가 서식지를 되살려 값을 내리고 중개료를 받음. 사슬 C의 원인과 이어짐.

### M10 [훈훈] 촌장의 비밀 장부 — 오토
1. 촌장이 마을 기금을 숨긴다는 소문.
2. 단서 잡템: 열쇠 없는 작은 금고.
3. 기금은 마을 축제와 낡은 우물 수리를 위해 몰래 모으던 것.
4. 엘프는 비밀 유지 수수료를 받고, 이후 사슬 D, H의 구역 복구에 기금을 활용.

### M11 [코미디] 가짜 보물 지도 — 하이디
1. 방랑 상인 하이디가 보물 지도를 팔고 다님.
2. 단서 잡템: 지도 귀퉁이의 숫자.
3. 대부분 가짜인데 한 장만 진짜. 하이디도 그 사실을 모름.
4. 진짜 지도는 던전 비밀 방을 가리키고, 사슬 G의 국자와 이어짐.

### M12 [코미디] 인형 쌍둥이의 흥정 — 보니, 보라
1. 두 소녀가 서로 심부름 값이 더 높다며 다툼. 엘프가 중재자로 지목됨.
2. 단서 잡템: 서로 바꿔 쓴 리본.
3. 둘은 남남인데 서로를 쌍둥이라고 우김. 이유는 용돈을 합쳐 모으려는 계획.
4. 엘프가 둘의 용돈 합병 계약서를 써 주고 수수료를 받음. 사슬 J의 인맥으로 쓰임.

### M13 [모험] 매가 물어 온 조각 — 하크
1. 사냥꾼 하크의 매 '금화'가 반짝이는 것을 물고 와서 사라짐.
2. 단서 잡템: 찢긴 문서 조각.
3. 문서는 마을 땅문서의 일부. 매 둥지는 던전 입구 근처 절벽.
4. 조각을 모으면 구역 복구에 필요. 사슬 H, G와 이어짐.

### M14 [경제] 새 가게를 열고 싶은 둘 — 카이, 로사
1. 전직 도둑이 가게 자금을 빌려 달라고 함.
2. 단서 잡템: 낡은 도둑 길드 회원증.
3. 이미 던전 금융에서 높은 이자로 빌린 상태.
4. 엘프가 대출을 갈아타 주고 수수료를 챙김. 사슬 A, I와 이어짐.

### M15 [괴담] 꽃이 웃는다 — 미나, 리라, 아넬
1. 꽃 축제 준비 중 꽃들이 밤에 소리를 낸다는 소문.
2. 단서 잡템: 꽃잎 속에 숨은 작은 알갱이.
3. 던전 1층의 마력이 새어 올라와 꽃이 변이.
4. 변이를 막는 대신 변이한 꽃을 비싸게 파는 엘프의 선택. 사슬 C와 이어짐.

## 소형 사슬 20개 (1~2단계, 흥정 포인트만 표기)
- S01 약초 배달 — 마르타. 가는 길이 위험할수록 수수료 인상 요구. 잡템: 빈 약병.
- S02 고양이 찾기 — 클라라. 고양이는 던전 안에서 쥐를 상대로 장사 중. 잡템: 작은 방울.
- S03 잃어버린 열쇠 — 페닉스. 열쇠가 저울 서랍 열쇠였음. 사슬 B와 연결. 잡템: 놋쇠 열쇠.
- S04 안경 닦는 천 — 에드먼. 천 한 장에 수수료 흥정. 학자의 변덕 대사. 잡템: 낡은 천.
- S05 전단 배포 — 로즈. 배포 장수만큼 보수. 엘프는 전단을 반으로 접어 절약. 잡템: 접힌 전단.
- S06 길 청소 — 조. 광장 길의 돌 하나를 들추면 압류 구역 표식이 나옴. 사슬 H 연결. 잡템: 표식 돌.
- S07 장작 모으기 — 오토. 장작 하나에 단가 협상. 잡템: 이끼 낀 장작.
- S08 잔돈 도둑 — 닉. 범인은 잔돈을 모아 엘프에게 선물하려던 소년. 사슬 F 연결. 잡템: 동전 주머니.
- S09 소음 민원 — 토비. 밤마다 지하에서 자장가 비슷한 소리. 사슬 C 연결. 잡템: 소리 나는 조개껍질.
- S10 빵 재료 — 빈센트. 밀가루 포대를 던전 1층에서 회수. 잡템: 밀가루 묻은 쪽지.
- S11 술통 운반 — 바우. 술통 하나 무게마다 수수료. 잡템: 술통 마개.
- S12 외상 장부 — 브란. 장부 사본을 찾아 달라는 의뢰. 사슬 A, F 연결. 잡템: 외상 영수증.
- S13 훈련 상대 — 도윈. 엘프가 공짜로 맞아 주면 시간당 보수가 오른다는 계약. 잡템: 나무 창.
- S14 가짜 근무자 — 에다. 경비 교대 때마다 가짜가 서 있는 소동. 잡템: 종이 투구.
- S15 사탕 — 피트. 사탕값 흥정, 엘프가 사탕 하나를 먹고 후회하는 장면. 잡템: 사탕 껍질.
- S16 시약 시험 — 이브. 엘프가 시약을 마셔 보는 대가로 수수료. 사슬 J 연결. 잡템: 유리병 조각.
- S17 말 목욕 — 조. 말 한 마리 목욕 값 흥정. 말 '당근'이 엘프를 알아봄. 잡템: 말 빗.
- S18 책 연체료 — 에드먼. 반납한 책에서 지도가 나옴. 잡템: 책갈피.
- S19 날아간 모자 — 하이디. 모자가 던전 입구에 걸림. 사슬 G 연결. 잡템: 깃털 모자.
- S20 허수아비 교체 — 오토. 허수아비 속에서 오래된 서류가 나옴. 사슬 D 연결. 잡템: 짚 속 서류.

## 단서 잡템 중복 점검 메모
대형 A~J와 중형·소형의 단서 잡템 이름이 서로 겹치지 않아야 한다. 겹치는 것이 있으면 이 파일에서 수정한다.

## 다음 묶음용 메모
중형·소형에서 아직 쓰지 않은 인물: 팀, 올로, 야닉, 세라, 이사벨, 아르노, 제니, 시안, 아리아, 그림자, 페리, 세실. 다음 사슬 묶음에서 우선 사용한다. 그림자(의뢰 중개인)는 사슬 F와 연결 가능한 고리로 남겨 둔다.
