# MASTER_70 — Lv1~70 메인 시나리오 설계 (봉인본)

> **절대 비공개.** 케인은 개발자이자 유일한 첫 플레이어다.
> 이 파일의 퀘스트 제목, 인물 이름, 사건, 복선, 정체, 결말을 케인에게 보여 주거나 요약하지 않는다.
> 케인에게는 "MAIN 001~010 완료" 같은 번호/개수와 필요한 시스템·에셋만 보고한다.
> 실제 대사는 10개 단위로 별도 구현하며 이 파일의 줄거리를 기준으로 한다.

## 0. 확정 방향

- 장르/톤: **자본주의 엘프 루크레아의 코믹 판타지 모험기.**
- 주인공 루크레아는 정의감보다 수익, 원가, 할인, 보상, 교역 이익을 먼저 본다.
- 루크레아가 착한 영웅으로 개과천선하는 이야기가 아니다. 끝까지 돈을 밝힌다.
- 다만 "내 것"의 범위가 자신의 지갑 → 거래처 → 동료 → 마을 → 세계로 넓어진다.
- 최종적으로는 돈을 벌기 위해 한 행동이 연쇄적으로 세계를 구하게 된다. 본인은 마지막까지 비용 정산을 먼저 한다.
- 메인퀘는 컷신 연속극이 아니다. **전투·교역·NPC 생활·던전·지역 이동 사이에 자연스럽게 끼어드는 RPG 퀘스트**다.
- 약 70개의 줄거리 퀘스트. 레벨당 평균 1개지만 실제로는 연속 2~3개 뒤 자유구간이 생겨도 된다.
- 해금은 최소 레벨 + 선행 퀘스트 + 장소/접촉 조건 조합. 지역 자체를 강제로 잠그지 않는다.
- 45개 기존 사슬(A~J, M01~M15, S01~S20)은 **서브퀘스트 풀**이다. 메인과 섞어 생활감을 만들되 모두 메인 복선으로 만들지 않는다.
- 현재 게임에 "본편"으로 연결된 M01~M05는 다음 메인 001~010 구현 때 **연쇄 서브퀘스트로 재분류**한다. 데이터/대사는 버리지 않는다.
- 기존 7지역: 봄 초원(T1) → 여름 숲(T2) → 가을 들판(T3) → 겨울 설원(T4) → 얼음 지대(T5) → 화산 지대(T6) → 늪지대(T7).
- **용의 산맥**은 선택/확장 지역. 메인 클리어에 필수로 만들지 않는다.
- 첫 지역 작은 마을/교역소는 Lv10 전후 메인에서 소개한다. 이후 전투와 교역이 함께 성장축이 된다.

## 1. 숨은 세계 뼈대

과거 일곱 지역의 길과 지하 던전은 단순 교통망이 아니라, 지맥을 고정하는 **일곱 개의 길목 인장**을 서로 연결하는 구조였다.
이 인장은 오래전 봉인된 존재 "네르바인"을 누르는 장치이기도 했다. 시대가 지나면서 의미가 잊혔고, 길목은 상업로·세관·창고·우물·광산·마을터 같은 평범한 시설로 전용되었다.

최근 인장 일부가 약해져 몬스터 이동, 물가 이상, 기후 이상, 던전 구조 변화, 이상한 수면 현상 등 서로 상관없어 보이는 일이 발생한다.
누군가 거대한 음모를 꾸민다기보다, 여러 사람의 작은 탐욕·실수·낡은 시설·우연이 겹쳐 봉인이 느슨해지는 쪽이 기본이다.
이 때문에 범인을 하나 잡으면 끝나는 구조가 아니라, 루크레아가 각 지역에서 **돈 되는 길을 복구하려고 문제를 고칠수록** 인장이 다시 연결된다.

루크레아가 노리는 최종 보상은 고대의 **대상단 특허장(대륙 통행·창고·세금 우선권을 보장하는 문서)** 이다.
루크레아는 그것을 세계를 지키는 성물로 보지 않고 "평생 통행세 안 내도 되는 종이"로 본다.
특허장은 사실 일곱 인장의 최종 소유자/관리자를 지정하는 마법계약이기도 하다.
최종부에서 루크레아가 네르바인을 쓰러뜨리고 특허장에 자기 이름을 올리는 순간 인장이 완성된다.
세계는 구해지지만 루크레아의 첫 반응은 특허권으로 얼마를 벌 수 있느냐이다.

### 주제적 규칙
1. 심각한 사건은 실제로 심각해야 한다. 개그 때문에 피해나 감정을 무효화하지 않는다.
2. 개그는 루크레아의 계산, 보수 흥정, NPC의 생활감에서 나온다.
3. "돈은 나쁘다"가 결론이 아니다. 탐욕과 거래, 책임, 계약의 차이를 코믹하게 다룬다.
4. 루크레아는 남을 돕고도 "공짜로 한 게 아니다"라고 우긴다.
5. 세계를 구하는 모든 핵심 행동은 플레이 당시에는 **수익/손해 방지/거래 확보**라는 즉각적 이유가 있어야 한다.

## 2. 특수 반복 등장 NPC (이름 포함 — 케인에게 공개 금지)

### 2-1. 카르도
- 에셋: assets/characters/hero 계열.
- 이미지 기준: 큰 검을 든 남자 검사.
- 성격: 마초, 무뚝뚝, 츤데레. 말보다 행동으로 돕는다.
- 기능: 어려운 전투에서 몇 번 동행하는 반고정 조력자. 파티 상주 캐릭터로 만들지 않는다.
- 루크레아와의 관계: 돈만 밝히는 태도를 못마땅해하지만, 위험하면 먼저 앞으로 나간다. 루크레아는 무료 경호원처럼 쓰려 한다.
- 재등장: Lv15 전후 첫 등장. 이후 Lv30대, Lv50대, 최종부에 상황이 맞으면 재등장.
- 비밀 원칙: 거창한 왕자/선택받은 자 설정은 주지 않는다. 평범하게 실력 있는 사람이라서 오히려 신뢰감이 생긴다.

### 2-2. 벨로라
- 에셋: assets/characters/dragon 계열.
- 정체: 약 800세의 어린 드래곤.
- 기능: 메인 최종빌런이 아닌 **지역형 사이드 빌런/경제적 라이벌**.
- 성격: 루크레아보다 더 돈에 미쳤으며 규모도 훨씬 크다. 산맥 하나를 기업처럼 운영한다.
- 용의 산맥 몬스터는 이름 뒤에 대리/과장/차장/부장/상무/전무 같은 직급이 붙는다.
- 몬스터를 노동자로 쓰며 생산량·납기·성과급을 말한다. 악덕 사장 개그지만 실제 위험도 존재.
- 루크레아와의 관계: 둘 다 돈을 사랑하지만, 루크레아는 직접 뛰고 흥정하는 소상공인형, 벨로라는 독점·착취형 대자본가라 충돌한다.
- 메인에 꼭 필요한 열쇠로 만들지 않는다. 선택 지역을 거치면 후반의 일부 문제를 다른 방식으로 풀 수 있는 정도만 허용.

### 2-3. 펙스
- 에셋: assets/characters/knight 계열을 우선 확인. 실제 그림이 중장갑+레이저총 캐릭터인지 구현 전 대조.
- 표면 신분: 외지 출신 용병.
- 실제: 이 공간에 잘못 떨어진 어리버리한 외계인. 귀환 수단을 잃었다.
- 기능: Lv20 전후부터 여관 죽돌이. 돈이 없어서 용병 일을 한다.
- 루크레아는 시세보다 싸게 고용하려고 매번 구슬린다.
- 과학기술 설명을 길게 하지 않는다. 본인도 현지 언어로 설명을 잘 못해 "빛나는 쇠막대" 정도로 얼버무리는 코미디.
- 메인 핵심 비밀의 정답을 알려주는 편리한 해설자로 쓰지 않는다.
- 가끔 고용/동행, 특정 장치 오작동 해결, 전투 보조에 쓰되 세계의 판타지 톤을 침식시키지 않는다.

### ACT 0 — "돈 벌 곳을 찾았습니다" / Lv1~9 / 본마을+T1

**MAIN_001 / Lv1 / 도착과 길드 등록**
- 시작: 루크레아가 큰 마을에 도착. 길드장 하르트가 기본 생활/의뢰 체계를 소개.
- 플레이: 길드 홀, 의뢰 게시판, 여관 위치 확인.
- 목적: UI 설명을 대사창으로만 하지 말고 실제로 걸어 다니게 한다.
- 개그: 가입비/보증금 얘기에 루크레아가 즉각 반응.
- 신규 에셋: 없음.

**MAIN_002 / Lv1 / 장사꾼의 필수품**
- 시작: 길드 등록 뒤 도구점·잡화점·무기점 동선 소개.
- 플레이: 상점 2~3곳 방문, 기본 판매/구매, 장비·감정·스크롤의 존재만 가볍게 노출.
- 목적: 마을 기능 소개.
- 신규 에셋: 없음.

**MAIN_003 / Lv2 / 물약 한 병의 가치**
- 시작: 초반 NPC가 물약점/약초상 이용을 시킨다.
- 플레이: HP 물약 1개 구매 → 성문 쪽 이동 → 던전 경비병과 대화.
- 목적: 소비품, 마을 밖 출구, 던전 입장 소개.
- 신규 에셋: 없음.

**MAIN_004 / Lv3 / 첫 던전 수익 계산**
- 시작: 던전 입구 경비병의 소소한 부탁.
- 플레이: 던전 1~3층 중 초반 적정 범위 탐색, 지정 물건 회수 또는 지정 몬스터 처치, 귀환.
- 목적: 층 이동·전투·드랍·귀환 루프 소개.
- 비밀: 회수물에 훗날 길목 인장과 같은 아주 작은 문양이 있으나 설명하지 않는다.
- 신규 에셋: 없음.

**MAIN_005 / Lv4 / 루크레아의 사업계획**
- 시작: 첫 수익 정산 후 루크레아가 "모험=위험한 일"이 아니라 "마진 좋은 일"로 이해한다.
- 플레이: 길드 의뢰 1건 또는 판매 1회 + 골드 목표 달성.
- 목적: 돈에 미친 루크레아의 정체성을 유쾌하게 확정. Discount/Overcharge 생활스킬과 성격 연결.
- 이 시점부터 초반 서브퀘스트 일부 해금.
- 신규 에셋: 없음.

**MAIN_006 / Lv5 / 값싼 정보**
- 시작: 여관 토비가 성 밖 길의 소문을 알려주며 아주 작은 부탁.
- 플레이: T1 필드 방문, 야영지 또는 작은 랜드마크 확인.
- 목적: 필드와 야영지 소개. 마을 NPC 퀘스트가 길드판 외에서도 생긴다는 학습.
- 신규 에셋: 없음.

**MAIN_007 / Lv6 / 돌아오는 길이 더 비싸다**
- 시작: 필드 운반/회수 의뢰.
- 플레이: 전투 후 물건 회수 → 마을 특정 상점에 전달.
- 목적: 퀘스트아이템 드랍과 전달형 기본 문법.
- 비밀: 회수물의 제작지가 현재 존재하지 않는 옛 교역소로 표기.
- 신규 에셋: 없음.

**MAIN_008 / Lv7 / 첫 손해**
- 시작: 루크레아가 싸다고 산 물건에서 작은 문제가 발생.
- 플레이: 상점 NPC/학자/길드장 사이를 돌며 해결.
- 목적: 모든 거래가 이익은 아니며 NPC 관계를 소개.
- 신규 에셋: 없음.

**MAIN_009 / Lv8 / 문밖의 가격표**
- 시작: 성문 밖 상인의 소문.
- 플레이: T1 필드 특정 몬스터/상자에서 지역 물품 확보.
- 목적: "지역마다 가치가 다르다"는 교역 개념의 전조.
- 신규 에셋: 없음.

**MAIN_010 / Lv9~10 / 첫 거래길**
- 시작: Lv10 도달 또는 MAIN_009 완료+조건.
- 플레이: 여름 숲(T2) 방향의 첫 작은 마을로 가는 길 확보, 상인협회/교역소와 첫 거래.
- 시스템: **첫 정식 교역 튜토리얼.** 그 마을에서 싸게 사고 본마을에서 비싸게 팔아 실제 차익을 경험.
- 비밀: 오래된 교역소 바닥의 문양이 MAIN_004 회수물과 일치.
- 신규 에셋: 기존 작은 마을/상인협회 재사용.

### ACT 1 — "돈 되는 길에는 사정이 있습니다" / Lv11~19 / T2

**MAIN_011 / Lv11 / 장사길의 통행료**
- 첫 교역로 반복 중 길이 막히는 사건. 통행 문제 해결.
- 전투+교역 혼합. 해결 후 해당 루트 거래 편의가 좋아짐.

**MAIN_012 / Lv12 / 싼 물건에는 이유가 있다**
- 지역 특산품 가격 폭락 원인 조사.
- 단순 몬스터 처치가 아니라 생산지 NPC→현장→몬스터 순서.

**MAIN_013 / Lv13 / 장부 밖의 물건**
- 교역소 장부에 없는 오래된 물품을 발견.
- 학자에게 가져가지만 큰 설명은 하지 않고 "옛 길 표식" 정도만 판정.

**MAIN_014 / Lv14 / 경비 없는 호송**
- 루크레아가 경호비를 아끼려다 위험한 운반을 혼자 맡음.
- 중간 난도 상승. 마지막에 정체불명의 검사가 잠깐 개입하되 이름은 끝에서만 공개 가능.

**MAIN_015 / Lv15 / 카르도**
- 카르도 정식 등장.
- 같은 던전/지역 목표가 겹쳐 일시 동행.
- 루크레아는 급료를 주지 않으려 하고 카르도는 "고용된 적 없다"고 받아침.
- 난도 높은 지정 몬스터 1종을 함께 처치.

**MAIN_016 / Lv16 / 같은 길, 다른 목적**
- 카르도와 두 번째 짧은 동행. 이번에는 수집/구출 요소 포함.

## 4. 서브퀘스트 45개 배치 원칙

기존 src/story.md / chains.md의 A~J, M01~M15, S01~S20 = 총 45개를 메인 사이에 분산한다.

- Lv4~9: 생활형/코미디형 소형·중형 위주. 루크레아 성격과 본마을 사람들을 익히게 한다.
- Lv10~19: 첫 교역·첫 외부지역과 맞는 경제/운반/실종 계열.
- Lv20~29: NPC 개인사와 마을 생활형 연쇄를 늘린다.
- Lv30~39: 중형 사슬과 과거 문서/구역 계열을 적당히 열어 메인 세계의 오래됨을 자연스럽게 보강.
- Lv40~49: 선택 용의 산맥 사이드퀘 및 코미디 비중을 높여 메인 긴장 상승을 완충.
- Lv50~59: 대형 사슬 일부가 본편과 간접 교차해 "예전 잡일이 지금 도움이 됨"을 체감.
- Lv60~69: 완료한 서브퀘 결과가 지원품, 할인, 짧은 대사, NPC 위치 변화 등으로 돌아오게 한다.
- 서브퀘를 안 해도 메인 클리어는 가능해야 한다.
- 아무 서브퀘나 억지로 세계멸망 복선으로 만들지 않는다. 최소 절반 이상은 정말 생활형 사건으로 끝낸다.
- M01~M05는 현재 잘못 본편으로 연결되어 있으므로 향후 UI/분류만 서브로 옮기고 내용은 재사용.

## 5. 실제 퀘스트 데이터 작성 규칙 (10개씩)

MAIN 001~010, 011~020 ... 061~070 순으로 구현한다.

각 퀘스트 데이터는 다음을 가진다.
- id
- 최소 레벨
- 선행 메인
- 시작 NPC/장소
- 시작 대사
- 2~6개 단계
- 단계 타입: talk / kill / collect / visit / deliver / trade / dungeon / escort(구현 가능할 때)
- 진행 중 NPC 대사
- 완료 대사
- 보상(경험치 비율, 골드, 아이템/해금)
- 후속 트리거
- 필요 에셋 ID(없으면 null)
- 숨은 continuity note(케인에게 비공개)

### 대사 톤
- 루크레아: 공손한 장사꾼 말투, 짧고 계산적. 숫자·원가·수수료·손해 얘기를 자주 하지만 매 줄 돈 농담은 금지.
- NPC마다 bible.md의 말투 유지.
- 한 대화창 1~2줄 정도.
- 감정 장면에서는 농담을 줄이고, 장면이 끝난 뒤 루크레아다운 한마디로 톤을 복구.
- 같은 돈 농담 반복 금지: 할인, 원가, 이자, 보증금, 감가, 운송비, 위험수당, 세금, 재고, 손익, 외상 등 소재를 분산.

## 6. 에셋 운영

- 기본은 기존 NPC/캐릭터/몬스터/건물/아이템 재사용.
- 새 이미지가 없어도 대사+기존 캐릭터+퀘스트아이템 아이콘으로 해결 가능하면 새 그림을 만들지 않는다.
- 정말 필요한 경우만 ASSET_STORY_### 번호로 기록.
- 케인에게 에셋을 요청할 때는 스포일러를 제거하고 제작 정보만 준다.
  예: "ASSET_STORY_004 — 기존 남성 검사 외형 유지, 상반신 놀란 표정 1개, 투명 PNG."
- "누구를 보고 놀라는지", "어느 반전 장면인지"는 말하지 않는다.
- 움직이는 장면도 기존 걷기/공격 프레임으로 해결 가능하면 신규 시트를 요구하지 않는다.

## 7. 구현 시 첫 수정 사항

1. 현재 quests.json의 M01~M05를 **메인에서 연쇄 서브퀘스트 분류로 이동**. 저장 호환은 유지.
2. MAIN_001부터 새 ID 체계로 시작.
3. 메인 금색 별 HUD는 MAIN 계열만 사용.
4. 서브퀘는 별도 표식/목록으로 분리하되 길드 반복의뢰 5개 한도와도 별개로 둔다.
5. 메인 001~003에서 길드/상점/여관/던전 동선을 자연스럽게 연결.
6. MAIN_010에서 기존 7지역 작은마을/상인협회와 첫 교역을 스토리로 연결.
7. MAIN_020 이후 펙스 여관 상주 훅, MAIN_015 이후 카르도 재등장 훅, MAIN_043 이후 벨로라/용의 산맥 훅을 추가.

## 8. 스포일러 차단 보고 규칙

케인에게 허용:
- "MAIN 001~010 작성 완료"
- "기존 에셋만 사용"
- "새 에셋 2개 필요"
- "전투/교역/동행 기능 연결"
- "검사 통과/실패"
- "다음 011~020 진행 여부"

케인에게 금지:
- 퀘스트 제목
- 새 NPC 이름
- 사건 내용
- 누가 재등장하는지
- 누가 중요한 인물인지
- 복선/반전/최종 보스 정체
- 엔딩 내용
- 신규 에셋이 필요한 스토리상의 이유

## 9. 연속성 체크리스트

각 10개 묶음 구현 뒤 내부적으로만 확인:
- 루크레아가 정의감 때문에 움직인 장면이 없는가?
- 돈 개그가 같은 형태로 반복되지 않는가?
- 지역 이동/권장 레벨이 progression.md와 맞는가?
- 메인 때문에 교역/파밍 자유시간이 사라지지 않는가?
- NPC가 자기 생활을 가진 사람처럼 보이는가?
- 카르도/펙스/벨로라가 지나치게 메인 중심으로 빨려들지 않는가?
- 기존 서브퀘 결과와 모순이 없는가?
- 초반의 사소한 물건/장소를 회수할 때 억지 반전이 되지 않는가?
- 신규 에셋 요구가 정말 필요한가?
- 케인에게 작업보고하면서 스포일러를 흘리지 않았는가?
